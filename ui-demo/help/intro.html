UI Demo
A read-only gallery of the widgets in ui-lib.pl, and of the existing tabs, forms, buttons and tables they are meant to be combined with. It is a reference for writing new modules, and is not part of the Webmin distribution.

This page is opened by the question mark at the top right of the module title, which ui_print_header shows when its help argument names a page in the module's help directory. The cog next to it opens the module configuration, listed in config.info.
