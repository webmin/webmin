Create Table
This page creates a table in the open SQLite database. Enter a table name and one row per column. Rows without a column name are ignored. Add More Columns shows four more rows without discarding your entries.

Each column uses one of these SQLite type affinities: INTEGER, TEXT, REAL, BLOB or NUMERIC. These are preferred storage types, not strict restrictions. A column that does not allow NULL needs a value or default when each database row is added.

The key setting controls row identity and uniqueness. An INTEGER primary key with autoincrement is the usual choice and is filled in automatically. Marking several columns as the primary key creates a composite key. Primary key columns do not allow NULL. A unique column rejects duplicate values without becoming the primary key.

A default value is stored as text unless it is a number, NULL, or one of CURRENT_TIME, CURRENT_DATE and CURRENT_TIMESTAMP.
